Host nativo (Windows)

O Chrome não consegue embutir o motor IE sozinho. É necessário instalar o host nativo (ChromeIETabHost no Windows. Ele registra Native Messaging e abre um visualizador WinForms com o controle WebBrowser (Trident / IE11).

  1. Em chrome://extensions, ative o Modo do desenvolvedor e carregue a pasta extension.
  2. Copie o ID da extensão abaixo.
  3. No Windows, abra PowerShell na pasta native-host e execute: 
    .\install.ps1 -ExtensionId SEU_ID_AQUI
  4. Reinicie o Chrome e teste “Abrir no IE”.

Aviso de segurança

O motor Trident/IE não recebe mais atualizações de segurança desde 2022. Use apenas com sites internos confiáveis e sistemas legados que você controla. Para a maioria dos casos corporativos modernos, prefira o IE Mode do Microsoft Edge.
