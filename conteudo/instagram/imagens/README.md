# Identidade visual NSL — posts Instagram

Paleta usada nas artes (definida para o pacote de conteúdo; sem manual oficial disponível):

| Papel | Cor | Hex |
|-------|-----|-----|
| Fundo | Azul-noite | `#0B1F3A` |
| Destaque | Ciano | `#00A8E8` |

**Estilo:** tech corporativo, tipografia sans-serif forte, poucos elementos, sem roxo/neon excessivo.
