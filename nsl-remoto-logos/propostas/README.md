# Propostas refinadas — NSL Remoto

Direção recomendada: **monograma N** (arquivos `nsl-recomendado-*`).

## Por quê esta direção
- Mais comercial e B2B do que ícones de monitor/nuvem/escudo
- Marca própria (monograma), não clipart de “acesso remoto”
- Funciona em fundo claro, escuro e como ícone de app
- Paleta navy + teal: confiança + tecnologia, sem visual genérico de IA

## Arquivos
| Arquivo | Uso |
|---|---|
| `nsl-recomendado-escuro.jpg` | Site, apresentação, dark UI |
| `nsl-recomendado-claro.jpg` | Proposta comercial, docs, e-mail |
| `nsl-recomendado-icone.jpg` | App / favicon / avatar |
| `nsl-proposta-A-monograma.jpg` | Direção A (base da recomendação) |
| `nsl-proposta-B-wordmark.jpg` | Alternativa wordmark-first (docs) |
| `nsl-proposta-C-selo.jpg` | Alternativa “segurança” (mais clichê) |
| `nsl-proposta-D-sistema.jpg` | Alternativa sistema ícone+lockup |

## Alternativas
- **B** — ótima para papel timbrado e contratos (mais tipográfica)
- **C** — comunica segurança rápido, mas o keyhole é mais óbvio
- **D** — mais “produto/app”; o símbolo está um pouco mais ocupado
