# Pasta pronta para o XAMPP

Esta pasta (`inspex`) já contém o site compilado.

## Instalação rápida

1. Copie a pasta `inspex` para `C:\xampp\htdocs\inspex`
2. Inicie o **Apache** no XAMPP
3. Abra **http://localhost/inspex/**

Ou use o arquivo `..\instalar-xampp.bat` (um clique).

Veja também: `..\INSTALAR-XAMPP.txt`
